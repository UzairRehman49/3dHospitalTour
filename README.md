# Muslim Specialty Hospital — 3D Walkthrough

Interactive 3D tour of Muslim Specialty Hospital, Jahanian, Khanewal, built from drawing set HS-023.

**Live:** https://uzairrehman49.github.io/3dHospitalTour/

`index.html` is a single self-contained file (three.js, building data and textures included). It is the build output of the `hospital-3d` project; rebuild there and copy `dist/index.html` here to update the site.
